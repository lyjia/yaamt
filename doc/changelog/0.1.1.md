# YAAMT 0.1.1

## Behavior changes

- WAV and AIFF metadata cannot be edited in the GUI, CLI or analyzers until full support lands (#74). Previously, edits appeared to be accepted and then failed on save.
- On M4A files, the initial key, mood, composer, ISRC, MusicBrainz and AcoustID tags cannot be edited, and the key and fingerprint analyzers skip M4A files. Previously, every such write raised an error.
- `yaamt analyze -w` with a BPM analyzer reports files as skipped, because the CLI does not yet select a BPM from the analyzer's candidates (#82). Previously, it failed at save.
- WAV files show empty fields in the Properties window because their tags cannot be read yet (#74). This predates 0.1.1.
